.nzip

Extensión .nzip

Un archivo con extensión .nzip es un archivo comprimido: como un archivo ZIP, contiene uno o más archivos y carpetas de tamaño reducido, y se crea con el programa NZip.

Qué es un archivo .nzip

El formato .nzip se creó para obtener archivos más pequeños y seguros: comprime los píxeles de las imágenes PNG con JPEG XL sin pérdida, recomprime sin pérdida JPEG, archivos ZIP y documentos de Office, y guarda una huella BLAKE3 de cada archivo para verificar que lo extraído es idéntico al original.

Un archivo .nzip puede estar protegido con contraseña (AES-256, que también cifra los nombres de los archivos), contener datos de recuperación para repararlo si se daña, estar firmado digitalmente o dividido en varias partes.

Cómo abrir un archivo .nzip

  1. Descarga NZip, gratuito para todos, para Windows, macOS o Linux.
  2. Haz doble clic en el archivo .nzip: se abre NZip y muestra su contenido.
  3. Elige «Extraer todo» o, en Windows, haz clic derecho en el archivo → «Extraer aquí». Cada archivo extraído se verifica.

Si quien recibe el archivo no puede instalar programas, NZip Pro puede crear un archivo autoextraíble (.exe) que se abre con un doble clic.

Preguntas frecuentes sobre los archivos .nzip

¿Puedo abrir un archivo .nzip con 7-Zip o WinRAR?

No: los archivos .nzip se abren con NZip, que es gratuito. En cambio, NZip también abre ZIP, RAR, 7z y los demás formatos más comunes.

¿Es seguro un archivo .nzip?

Un archivo comprimido es un contenedor: su seguridad depende de los archivos que contiene y de quién te lo ha enviado. NZip verifica la integridad de cada archivo, pero no sustituye al antivirus.

¿Cómo convierto un archivo .nzip a ZIP?

Extrae el contenido con NZip y vuelve a comprimir la carpeta en formato ZIP. En sentido contrario, NZip convierte ZIP, RAR, 7z y otros formatos a .nzip con un clic.

El archivo está dañado: ¿puedo recuperarlo?

Sí, si se creó con datos de recuperación: NZip lo repara desde el menú Herramientas o con el comando nzip r.

NZip dice que el archivo requiere una versión más reciente: ¿por qué?

El archivo usa una función introducida en una versión posterior de NZip, por ejemplo la compresión JPEG XL de las imágenes PNG (NZip 3.2). Actualiza NZip gratis desde el sitio oficial: las versiones nuevas abren siempre los archivos creados por las anteriores.
