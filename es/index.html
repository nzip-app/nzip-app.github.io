Por qué NZip

Más pequeños que 7-Zip

Píxeles de las imágenes PNG en JPEG XL sin pérdida, recompresión de JPEG, ZIP y documentos de Office, y compresores modernos elegidos para cada tipo de datos.

Cada archivo, verificado

Antes de cerrar el archivo comprimido, NZip lo vuelve a leer y compara cada archivo con el original (BLAKE3). Al extraer, cada archivo se comprueba de nuevo.

Reparables

Los datos de recuperación permiten reparar un archivo dañado por un disco o una descarga defectuosos.

Todos los formatos

Abre y extrae ZIP, RAR, 7z, TAR, GZ, BZ2, XZ, ZSTD, LZH, ARJ, CAB, ISO, WIM y más, y los convierte a .nzip con un clic.

Seguros

Cifrado AES-256 del contenido y de los nombres de archivo. Con NZip Pro: firma digital y cifrado por destinatario, sin contraseñas que intercambiar.

Integrado en el sistema

Menús del Explorador de archivos de Windows 11 y 10, «Enviar a», vistas previas e iconos; Finder en macOS; Dolphin, Nautilus y Nemo en Linux.

Legibles para siempre

Formato abierto y documentado, compresión determinista y archivos de referencia verificados en cada versión: un .nzip de hoy se abrirá también dentro de 20 años.

7 idiomas

Italiano, English, Español, Français, Deutsch, Русский, 中文: programa, menús y línea de comandos.

Datos de prueba

  • Código fuente — código fuente oficial de CPython 3.13.7, archivo Python-3.13.7.tar.xz de https://www.python.org/ftp/python/3.13.7/ (licencia PSF).
  • Copias de seguridad de código fuente — carpeta de copias de seguridad de un proyecto con tres versiones consecutivas y oficiales de CPython, 3.13.5, 3.13.6 y 3.13.7, una junto a otra (archivos Python-3.13.x.tar.xz de https://www.python.org/ftp/python/, licencia PSF): representa guardar una copia de cada versión.
  • Imágenes — las 24 imágenes PNG de la Kodak Lossless True Color Image Suite de https://r0k.us/graphics/kodak/ (publicadas por Kodak para uso libre) y 40 fotos JPEG originales de la misión Apollo 11 de la NASA Image and Video Library, https://images.nasa.gov (dominio público).
  • Documentos — bloque 000 del corpus Govdocs1 (documentos recopilados de sitios web del gobierno de los Estados Unidos, dominio público, creado para la investigación), archivo 000.zip de https://digitalcorpora.org/corpora/file-corpora/files/

El script bench_data.py descarga todos los archivos de las fuentes indicadas y verifica su huella SHA-256, así cualquiera obtiene exactamente los mismos datos.

Método

  • Una ejecución por programa, todas en el mismo ordenador, con la carpeta ya leída una vez (mismas condiciones para todos).
  • Para cada programa, el ajuste de compresión más alto documentado por su fabricante; para 7-Zip, también el ajuste normal.
  • Se mide el tamaño del archivo en bytes y el tiempo desde el inicio hasta el final de cada comando.
  • Cada archivo comprimido se extrae y cada fichero se compara con el original (SHA-256): un resultado solo se publica si es idéntico.
  • Los tiempos de NZip incluyen la verificación completa del archivo, que los demás programas no realizan.

Para repetir las mediciones

  1. Instala NZip, 7-Zip 26.02 y, si quieres, WinRAR 7.13 y zstd 1.5.7; también necesitas Python 3.
  2. Descarga los scripts bench_data.py (con bench_data.sha256.json) y bench.py.
  3. Ejecuta: python bench_data.py dati — descarga y verifica los datos de prueba en la carpeta «dati».
  4. Ejecuta: python bench.py risultati.json "Codice sorgente=dati\sorgenti" "Backup di sorgenti=dati\backup" Immagini=dati\immagini Documenti=dati\documenti
  5. Compara el archivo risultati.json con los datos brutos publicados.

Preguntas frecuentes

¿NZip es realmente gratis también para empresas?

Sí. La edición NZip es gratuita para cualquiera y para cualquier uso, también comercial. Pro y Enterprise añaden funciones avanzadas para profesionales y empresas.

¿Quien recibe un archivo .nzip tiene que instalar NZip?

Para abrir un .nzip se necesita NZip, que es gratis. Si el destinatario no puede instalar nada, con NZip Pro puedes crear un archivo autoextraíble (.exe) que se abre con un doble clic.

¿Puede NZip sustituir a WinRAR o 7-Zip?

Sí: abre y extrae ZIP, RAR, 7z y los demás formatos habituales, y puede ser tu programa predeterminado. Al desinstalarlo, se restauran las asociaciones anteriores.

¿Mis archivos se podrán leer en el futuro?

Sí. El formato está documentado, cada versión de NZip debe extraer bit a bit los archivos de todas las versiones anteriores y el programa de extracción siempre será gratuito.

¿NZip envía datos por internet?

NZip no envía tus archivos ni datos personales. La app comprueba una vez al día en GitHub si hay una versión nueva (una solicitud anónima que se puede desactivar en Ajustes); en Windows la actualización se instala solo después de verificar la firma digital del autor. Las licencias se activan con un archivo firmado, sin comprobaciones en línea.
