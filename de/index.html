Warum NZip

Kleiner als 7-Zip

PNG-Pixel als verlustfreies JPEG XL, Rekompression von JPEG, ZIP und Office-Dokumenten, moderne Kompressoren passend zu jedem Datentyp.

Jede Datei geprüft

Bevor NZip das Archiv abschließt, liest es alles erneut ein und vergleicht jede Datei mit dem Original (BLAKE3). Beim Entpacken wird jede Datei nochmals geprüft.

Reparierbar

Wiederherstellungsdaten reparieren Archive, die durch einen defekten Datenträger oder einen fehlerhaften Download beschädigt wurden.

Alle Formate

Öffnet und entpackt ZIP, RAR, 7z, TAR, GZ, BZ2, XZ, ZSTD, LZH, ARJ, CAB, ISO, WIM und mehr – und wandelt sie mit einem Klick in .nzip um.

Sicher

AES-256-Verschlüsselung von Inhalt und Dateinamen. Mit NZip Pro: digitale Signatur und Verschlüsselung für Empfänger – ganz ohne Passwortaustausch.

Nahtlos integriert

Kontextmenü im Datei-Explorer von Windows 11 und 10, „Senden an“, Vorschauen und Symbole; Finder unter macOS; Dolphin, Nautilus und Nemo unter Linux.

Für immer lesbar

Offenes, dokumentiertes Format, deterministische Kompression, Referenzarchive bei jeder Version geprüft: Ein .nzip von heute lässt sich auch in 20 Jahren noch öffnen.

Testdaten

  • Quellcode — offizieller Quellcode von CPython 3.13.7, Datei Python-3.13.7.tar.xz von https://www.python.org/ftp/python/3.13.7/ (PSF-Lizenz).
  • Quellcode-Sicherungen — Sicherungsordner eines Projekts mit drei aufeinanderfolgenden offiziellen CPython-Versionen, 3.13.5, 3.13.6 und 3.13.7, nebeneinander (Dateien Python-3.13.x.tar.xz von https://www.python.org/ftp/python/, PSF-Lizenz): steht für das Aufbewahren einer Kopie jeder Version.
  • Bilder — die 24 PNG-Bilder der Kodak Lossless True Color Image Suite von https://r0k.us/graphics/kodak/ (von Kodak zur freien Verwendung freigegeben) und 40 originale JPEG-Fotos der Mission Apollo 11 aus der NASA Image and Video Library, https://images.nasa.gov (gemeinfrei).
  • Dokumente — Block 000 des Korpus Govdocs1 (Dokumente von Websites der US-Regierung, gemeinfrei, für die Forschung erstellt), Datei 000.zip von https://digitalcorpora.org/corpora/file-corpora/files/

Das Skript bench_data.py lädt alle Dateien von den angegebenen Quellen herunter und prüft ihren SHA-256-Fingerabdruck, sodass jeder genau dieselben Daten erhält.

Methode

  • Ein Durchlauf pro Programm, alle auf demselben Computer, mit bereits einmal gelesenem Ordner (gleiche Bedingungen für alle).
  • Für jedes Programm die höchste vom Hersteller dokumentierte Kompressionseinstellung; für 7-Zip zusätzlich die normale Einstellung.
  • Gemessen werden die Größe des Archivs in Byte und die Zeit vom Start bis zum Ende jedes Befehls.
  • Jedes Archiv wird entpackt und jede Datei mit dem Original verglichen (SHA-256): Ein Ergebnis wird nur veröffentlicht, wenn es identisch ist.
  • Die Zeiten von NZip enthalten die vollständige Prüfung des Archivs, die andere Programme nicht durchführen.

So wiederholen Sie die Messungen

  1. Installieren Sie NZip, 7-Zip 26.02 und bei Bedarf WinRAR 7.13 und zstd 1.5.7; außerdem benötigen Sie Python 3.
  2. Laden Sie die Skripte bench_data.py (mit bench_data.sha256.json) und bench.py herunter.
  3. Führen Sie aus: python bench_data.py dati — lädt die Testdaten in den Ordner „dati“ herunter und prüft sie.
  4. Führen Sie aus: python bench.py risultati.json "Codice sorgente=dati\sorgenti" "Backup di sorgenti=dati\backup" Immagini=dati\immagini Documenti=dati\documenti
  5. Vergleichen Sie die Datei risultati.json mit den veröffentlichten Rohdaten.

Häufige Fragen

Ist NZip wirklich auch für Unternehmen kostenlos?

Ja. Die Edition NZip ist für alle und für jeden Zweck kostenlos, auch kommerziell. Pro und Enterprise bieten zusätzliche Funktionen für Profis und Unternehmen.

Muss der Empfänger einer .nzip-Datei NZip installieren?

Zum Öffnen einer .nzip-Datei wird das kostenlose NZip benötigt. Kann der Empfänger nichts installieren, erstellen Sie mit NZip Pro ein selbstentpackendes Archiv (.exe), das sich per Doppelklick öffnet.

Kann NZip WinRAR oder 7-Zip ersetzen?

Ja: NZip öffnet und entpackt ZIP, RAR, 7z und die anderen gängigen Formate und kann als Standardprogramm festgelegt werden. Bei der Deinstallation werden die vorherigen Dateizuordnungen wiederhergestellt.

Sind meine Archive auch in Zukunft lesbar?

Ja. Das Format ist dokumentiert, jede NZip-Version muss die Archive aller früheren Versionen bitgenau entpacken, und das Entpacken bleibt immer kostenlos.

Sendet NZip Daten ins Internet?

NZip sendet weder Ihre Dateien noch persönliche Daten. Die App prüft einmal täglich auf GitHub, ob es eine neue Version gibt (eine anonyme Anfrage, in den Einstellungen abschaltbar); unter Windows wird ein Update erst nach Prüfung der digitalen Signatur des Autors installiert. Lizenzen werden mit einer signierten Datei aktiviert, ohne Online-Prüfung.
