Dateiendung .nzip

Eine Datei mit der Endung .nzip ist ein komprimiertes Archiv: Wie eine ZIP-Datei enthält sie eine oder mehrere verkleinerte Dateien und Ordner und wird mit dem Programm NZip erstellt.

Was ist eine .nzip-Datei?

Das .nzip-Format wurde für kleinere und sicherere Archive entwickelt: Es komprimiert die Pixel von PNG-Bildern verlustfrei mit JPEG XL, rekomprimiert JPEG-Bilder, ZIP-Dateien und Office-Dokumente verlustfrei und speichert einen BLAKE3-Fingerabdruck jeder Datei, um zu prüfen, dass das Entpackte mit dem Original identisch ist.

Ein .nzip-Archiv kann mit einem Passwort geschützt sein (AES-256, das auch die Dateinamen verschlüsselt), Wiederherstellungsdaten zur Reparatur bei Beschädigung enthalten, digital signiert oder in mehrere Teile aufgeteilt sein.

Wie öffnet man eine .nzip-Datei?

  1. Laden Sie NZip herunter – kostenlos für alle, für Windows, macOS oder Linux.
  2. Doppelklicken Sie auf die .nzip-Datei: NZip öffnet sich und zeigt den Inhalt an.
  3. Wählen Sie „Alle extrahieren“ oder klicken Sie unter Windows mit der rechten Maustaste auf die Datei → „Hier extrahieren“. Jede extrahierte Datei wird überprüft.

Wenn der Empfänger keine Programme installieren kann, erstellt NZip Pro ein selbstextrahierendes Archiv (.exe), das sich per Doppelklick öffnet.

Häufige Fragen zu .nzip-Dateien

Kann ich eine .nzip-Datei mit 7-Zip oder WinRAR öffnen?

Nein: .nzip-Dateien werden mit NZip geöffnet, das kostenlos ist. NZip öffnet dagegen auch ZIP, RAR, 7z und die anderen gängigen Formate.

Ist eine .nzip-Datei sicher?

Ein Archiv ist ein Container: Die Sicherheit hängt von den enthaltenen Dateien ab und davon, wer es Ihnen geschickt hat. NZip prüft die Integrität jeder Datei, ersetzt aber kein Antivirenprogramm.

Wie konvertiere ich eine .nzip-Datei in ZIP?

Entpacken Sie den Inhalt mit NZip und komprimieren Sie den Ordner erneut im ZIP-Format. Umgekehrt konvertiert NZip ZIP, RAR, 7z und andere Formate mit einem Klick in .nzip.

Das Archiv ist beschädigt: Kann ich es wiederherstellen?

Ja, wenn es mit Wiederherstellungsdaten erstellt wurde: NZip repariert es über das Menü Werkzeuge oder mit dem Befehl nzip r.

NZip meldet, dass das Archiv eine neuere Version benötigt: warum?

Das Archiv nutzt eine Funktion aus einer späteren NZip-Version, zum Beispiel die JPEG-XL-Kompression von PNG-Bildern (NZip 3.2). Aktualisieren Sie NZip kostenlos über die offizielle Website: Neuere Versionen öffnen immer die Archive älterer Versionen.
