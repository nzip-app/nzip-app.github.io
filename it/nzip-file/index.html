.nzip

Estensione .nzip

Un file con estensione .nzip è un archivio compresso: come un file ZIP contiene uno o più file e cartelle ridotti di dimensione, ed è creato con il programma NZip.

Che cos'è un file .nzip

Il formato .nzip è stato creato per ottenere archivi più piccoli e sicuri: comprime i pixel delle immagini PNG con JPEG XL senza perdite, ricomprime senza perdite JPEG, file ZIP e documenti Office, e registra un'impronta BLAKE3 di ogni file per verificare che ciò che viene estratto sia identico all'originale.

Un archivio .nzip può essere protetto con password (AES-256, che cifra anche i nomi dei file), contenere dati di ripristino per ripararlo se si danneggia, essere firmato digitalmente o diviso in più parti.

Come aprire un file .nzip

  1. Scarica NZip, gratuito per tutti, per Windows, macOS o Linux.
  2. Fai doppio clic sul file .nzip: si apre NZip e mostra il contenuto.
  3. Scegli «Estrai tutto» oppure, su Windows, fai clic destro sul file → «Estrai qui». Ogni file estratto viene verificato.

Se chi riceve l'archivio non può installare programmi, NZip Pro può creare un archivio autoestraente (.exe) che si apre con un doppio clic.

Domande frequenti sui file .nzip

Posso aprire un file .nzip con 7-Zip o WinRAR?

No: i file .nzip si aprono con NZip, che è gratuito. NZip invece apre anche ZIP, RAR, 7z e gli altri formati più diffusi.

Un file .nzip è sicuro?

Un archivio è un contenitore: la sicurezza dipende dai file che contiene e da chi te lo ha inviato. NZip verifica l'integrità di ogni file ma non sostituisce l'antivirus.

Come converto un file .nzip in ZIP?

Estrai il contenuto con NZip e comprimi di nuovo la cartella in formato ZIP. Nel senso opposto, NZip converte ZIP, RAR, 7z e altri formati in .nzip con un clic.

L'archivio è danneggiato: posso recuperarlo?

Sì, se è stato creato con i dati di ripristino: NZip lo ripara dal menu Strumenti o con il comando nzip r.

NZip dice che l'archivio richiede una versione più recente: perché?

L'archivio usa una funzione introdotta in una versione successiva di NZip, ad esempio la compressione JPEG XL delle immagini PNG (NZip 3.2). Aggiorna NZip gratuitamente dal sito ufficiale: le versioni nuove aprono sempre gli archivi creati da quelle precedenti.
