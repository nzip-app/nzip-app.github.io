Pourquoi NZip

Plus petites qu'avec 7-Zip

Pixels des images PNG en JPEG XL sans perte, recompression des JPEG, ZIP et documents Office, et compresseurs modernes choisis pour chaque type de données.

Chaque fichier vérifié

Avant de fermer l'archive, NZip la relit et compare chaque fichier avec l'original (BLAKE3). À l'extraction, chaque fichier est de nouveau contrôlé.

Réparables

Les données de récupération permettent de réparer une archive endommagée par un disque ou un téléchargement défectueux.

Tous les formats

Ouvre et extrait ZIP, RAR, 7z, TAR, GZ, BZ2, XZ, ZSTD, LZH, ARJ, CAB, ISO, WIM et d'autres, et les convertit en .nzip en un clic.

Sécurisées

Chiffrement AES-256 du contenu et des noms de fichiers. Avec NZip Pro : signature numérique et chiffrement par destinataire, sans mot de passe à échanger.

Intégré au système

Menus de l'Explorateur de fichiers de Windows 11 et 10, « Envoyer vers », aperçus et icônes ; Finder sur macOS ; Dolphin, Nautilus et Nemo sur Linux.

Lisibles pour toujours

Format ouvert et documenté, compression déterministe, archives de référence vérifiées à chaque version : un .nzip créé aujourd'hui s'ouvrira encore dans 20 ans.

Italiano, English, Español, Français, Deutsch, Русский, 中文 : logiciel, menus et ligne de commande.

Données de test

  • Code source — code source officiel de CPython 3.13.7, fichier Python-3.13.7.tar.xz depuis https://www.python.org/ftp/python/3.13.7/ (licence PSF).
  • Sauvegardes de code source — dossier de sauvegarde d'un projet contenant trois versions officielles consécutives de CPython, 3.13.5, 3.13.6 et 3.13.7, côte à côte (fichiers Python-3.13.x.tar.xz de https://www.python.org/ftp/python/, licence PSF) : cela représente la conservation d'une copie à chaque version.
  • Images — les 24 images PNG de la Kodak Lossless True Color Image Suite depuis https://r0k.us/graphics/kodak/ (publiées par Kodak pour un usage libre) et 40 photos JPEG originales de la mission Apollo 11 issues de la NASA Image and Video Library, https://images.nasa.gov (domaine public).
  • Documents — bloc 000 du corpus Govdocs1 (documents collectés sur des sites du gouvernement des États-Unis, domaine public, créé pour la recherche), fichier 000.zip depuis https://digitalcorpora.org/corpora/file-corpora/files/

Le script bench_data.py télécharge tous les fichiers depuis les sources indiquées et vérifie leur empreinte SHA-256 : ainsi, chacun obtient exactement les mêmes données.

Méthode

  • Une exécution par logiciel, tous sur le même ordinateur, avec le dossier déjà lu une fois (mêmes conditions pour tous).
  • Pour chaque logiciel, le réglage de compression le plus élevé documenté par l'éditeur ; pour 7-Zip, également le réglage normal.
  • On mesure la taille de l'archive en octets et le temps entre le lancement et la fin de chaque commande.
  • Chaque archive est extraite et chaque fichier est comparé avec l'original (SHA-256) : un résultat n'est publié que s'il est identique.
  • Les temps de NZip incluent la vérification complète de l'archive, que les autres logiciels n'effectuent pas.

Pour refaire les mesures

  1. Installez NZip, 7-Zip 26.02 et, si vous le souhaitez, WinRAR 7.13 et zstd 1.5.7 ; Python 3 est également nécessaire.
  2. Téléchargez les scripts bench_data.py (avec bench_data.sha256.json) et bench.py.
  3. Exécutez : python bench_data.py dati — télécharge et vérifie les données de test dans le dossier « dati ».
  4. Exécutez : python bench.py risultati.json "Codice sorgente=dati\sorgenti" "Backup di sorgenti=dati\backup" Immagini=dati\immagini Documenti=dati\documenti
  5. Comparez le fichier risultati.json avec les données brutes publiées.

Questions fréquentes

NZip est-il vraiment gratuit, même pour les entreprises ?

Oui. L'édition NZip est gratuite pour tous et pour tout usage, y compris commercial. Pro et Enterprise ajoutent des fonctionnalités avancées pour les professionnels et les entreprises.

Le destinataire d'un fichier .nzip doit-il installer NZip ?

Pour ouvrir un .nzip, il faut NZip, qui est gratuit. Si le destinataire ne peut rien installer, NZip Pro vous permet de créer une archive auto-extractible (.exe) qui s'ouvre d'un double-clic.

NZip peut-il remplacer WinRAR ou 7-Zip ?

Oui : il ouvre et extrait ZIP, RAR, 7z et les autres formats courants, et peut devenir votre logiciel par défaut. À la désinstallation, les associations précédentes sont restaurées.

Mes archives seront-elles lisibles à l'avenir ?

Oui. Le format est documenté, chaque version de NZip doit extraire bit à bit les archives de toutes les versions précédentes, et le programme d'extraction reste toujours gratuit.

NZip envoie-t-il des données sur internet ?

NZip n'envoie jamais vos fichiers ni vos données personnelles. L'application vérifie une fois par jour sur GitHub si une nouvelle version existe (requête anonyme, désactivable dans les Paramètres) ; sous Windows, une mise à jour n'est installée qu'après vérification de la signature numérique de l'auteur. Les licences s'activent avec un fichier signé, sans vérification en ligne.
