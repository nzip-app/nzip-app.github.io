Why NZip

Smaller than 7-Zip

PNG pixels stored as lossless JPEG XL, recompression of JPEG, ZIP and Office documents, and modern compressors picked for each type of data.

Every file verified

Before closing the archive, NZip reads it back and compares every file with the original (BLAKE3). On extraction, every file is checked again.

Repairable

Recovery data lets you repair an archive damaged by a faulty disk or a broken download.

Every format

Opens and extracts ZIP, RAR, 7z, TAR, GZ, BZ2, XZ, ZSTD, LZH, ARJ, CAB, ISO, WIM and more, and converts them to .nzip in one click.

Secure

AES-256 encryption of both contents and file names. With NZip Pro: digital signatures and recipient-based encryption, no passwords to share.

Built into your system

File Explorer menus on Windows 11 and 10, “Send to”, previews and icons; Finder on macOS; Dolphin, Nautilus and Nemo on Linux.

Readable forever

Open, documented format, deterministic compression, reference archives verified with every release: a .nzip made today will still open 20 years from now.

How to reproduce the benchmarks

The comparison is designed to be fair and verifiable: anyone can repeat the measurements with the same programs, the same versions and the same commands.

Test data

  • Source code — official source code of CPython 3.13.7, file Python-3.13.7.tar.xz from https://www.python.org/ftp/python/3.13.7/ (PSF license).
  • Source code backups — a project's backup folder with three consecutive official CPython releases, 3.13.5, 3.13.6 and 3.13.7, side by side (files Python-3.13.x.tar.xz from https://www.python.org/ftp/python/, PSF license): it represents keeping a copy of every release.
  • Images — the 24 PNG images of the Kodak Lossless True Color Image Suite from https://r0k.us/graphics/kodak/ (released by Kodak for unrestricted use) and 40 original JPEG photos of the Apollo 11 mission from the NASA Image and Video Library, https://images.nasa.gov (public domain).
  • Documents — block 000 of the Govdocs1 corpus (documents collected from United States government websites, public domain, created for research), file 000.zip from https://digitalcorpora.org/corpora/file-corpora/files/

The bench_data.py script downloads all the files from the sources listed and verifies their SHA-256 fingerprint, so anyone gets exactly the same data.

Method

  • One run per program, all on the same computer, with the folder already read once (same conditions for all).
  • For each program, the highest compression setting documented by its developer; for 7-Zip, the normal setting as well.
  • We measure the archive size in bytes and the time from start to finish of each command.
  • Every archive is extracted and every file is compared with the original (SHA-256): a result is published only if identical.
  • NZip times include full verification of the archive, which the other programs don't do.

To repeat the measurements

  1. Install NZip, 7-Zip 26.02 and, if you like, WinRAR 7.13 and zstd 1.5.7; you also need Python 3.
  2. Download the bench_data.py script (with bench_data.sha256.json) and bench.py.
  3. Run: python bench_data.py dati — downloads and verifies the test data in the “dati” folder.
  4. Run: python bench.py risultati.json "Codice sorgente=dati\sorgenti" "Backup di sorgenti=dati\backup" Immagini=dati\immagini Documenti=dati\documenti
  5. Compare the risultati.json file with the published raw data.

Frequently asked questions

Is NZip really free for businesses too?

Yes. The NZip edition is free for anyone and for any use, commercial included. Pro and Enterprise add advanced features for professionals and companies.

Does whoever receives a .nzip file need to install NZip?

Opening a .nzip requires NZip, which is free. If the recipient can't install anything, NZip Pro lets you create a self-extracting archive (.exe) that opens with a double-click.

Can NZip replace WinRAR or 7-Zip?

Yes: it opens and extracts ZIP, RAR, 7z and the other common formats, and can become your default program. When you uninstall it, your previous file associations are restored.

Will my archives still be readable in the future?

Yes. The format is documented, every version of NZip must extract archives from all previous versions bit for bit, and the extraction program always stays free.

Does NZip send data over the internet?

NZip never sends your files or personal data. The app checks GitHub once a day for a new version (an anonymous request, which can be turned off in the Settings); on Windows an update is installed only after verifying the author's digital signature. Licenses are activated with a signed file, with no online checks.
