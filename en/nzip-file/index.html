.nzip

.nzip file extension

A file with the .nzip extension is a compressed archive: like a ZIP file, it contains one or more files and folders reduced in size, and it is created with the NZip program.

What is a .nzip file

The .nzip format was created to get smaller and safer archives: it compresses the pixels of PNG images with lossless JPEG XL, recompresses JPEG images, ZIP files and Office documents without loss, and stores a BLAKE3 fingerprint of every file to verify that what is extracted is identical to the original.

A .nzip archive can be password-protected (AES-256, which also encrypts file names), contain recovery data to repair it if it gets damaged, be digitally signed or split into multiple parts.

How to open a .nzip file

  1. Download NZip, free for everyone, for Windows, macOS or Linux.
  2. Double-click the .nzip file: NZip opens and shows its contents.
  3. Choose “Extract all” or, on Windows, right-click the file → “Extract here”. Every extracted file is verified.

If the recipient cannot install programs, NZip Pro can create a self-extracting archive (.exe) that opens with a double-click.

Frequently asked questions about .nzip files

Can I open a .nzip file with 7-Zip or WinRAR?

No: .nzip files are opened with NZip, which is free. NZip, on the other hand, also opens ZIP, RAR, 7z and the other most common formats.

Is a .nzip file safe?

An archive is a container: its safety depends on the files it contains and on who sent it to you. NZip verifies the integrity of every file but does not replace your antivirus.

How do I convert a .nzip file to ZIP?

Extract the contents with NZip and compress the folder again in ZIP format. The other way round, NZip converts ZIP, RAR, 7z and other formats to .nzip with one click.

The archive is damaged: can I recover it?

Yes, if it was created with recovery data: NZip repairs it from the Tools menu or with the nzip r command.

NZip says the archive needs a newer version: why?

The archive uses a feature introduced in a later version of NZip, for example the JPEG XL compression of PNG images (NZip 3.2). Update NZip for free from the official website: newer versions always open the archives created by older ones.
