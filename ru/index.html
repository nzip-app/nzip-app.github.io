Почему NZip

Меньше, чем 7-Zip

Пиксели изображений PNG в JPEG XL без потерь, пересжатие JPEG, ZIP и документов Office, современные алгоритмы сжатия под каждый тип данных.

Проверка каждого файла

Перед завершением NZip перечитывает архив и сверяет каждый файл с оригиналом (BLAKE3). При распаковке каждый файл проверяется снова.

Восстанавливаемые

Данные для восстановления позволяют исправить архив, повреждённый сбойным диском или неудачной загрузкой.

Все форматы

Открывает и распаковывает ZIP, RAR, 7z, TAR, GZ, BZ2, XZ, ZSTD, LZH, ARJ, CAB, ISO, WIM и другие — и конвертирует их в .nzip одним щелчком.

Безопасные

Шифрование AES-256 содержимого и имён файлов. В NZip Pro: цифровая подпись и шифрование для получателей — без обмена паролями.

Встроен в систему

Меню Проводника Windows 11 и 10, «Отправить», эскизы и значки; Finder в macOS; Dolphin, Nautilus и Nemo в Linux.

Читаемые всегда

Открытый документированный формат, детерминированное сжатие, эталонные архивы проверяются в каждой версии: сегодняшний .nzip откроется и через 20 лет.

Тестовые данные

  • Исходный код — официальный исходный код CPython 3.13.7, файл Python-3.13.7.tar.xz с https://www.python.org/ftp/python/3.13.7/ (лицензия PSF).
  • Резервные копии исходного кода — папка резервных копий проекта с тремя последовательными официальными версиями CPython — 3.13.5, 3.13.6 и 3.13.7 — рядом друг с другом (файлы Python-3.13.x.tar.xz с https://www.python.org/ftp/python/, лицензия PSF): так выглядит хранение копии каждого выпуска.
  • Изображения — 24 изображения PNG из Kodak Lossless True Color Image Suite с https://r0k.us/graphics/kodak/ (опубликованы Kodak для свободного использования) и 40 оригинальных фотографий JPEG миссии Apollo 11 из NASA Image and Video Library, https://images.nasa.gov (общественное достояние).
  • Документы — блок 000 корпуса Govdocs1 (документы, собранные с сайтов правительства США, общественное достояние, создан для исследований), файл 000.zip с https://digitalcorpora.org/corpora/file-corpora/files/

Скрипт bench_data.py скачивает все файлы из указанных источников и проверяет их отпечаток SHA-256, поэтому любой получает точно такие же данные.

Методика

  • Один запуск на программу, все на одном и том же компьютере, папка предварительно прочитана один раз (одинаковые условия для всех).
  • Для каждой программы — максимальная настройка сжатия, документированная разработчиком; для 7-Zip — также обычная настройка.
  • Измеряются размер архива в байтах и время от запуска до завершения каждой команды.
  • Каждый архив распаковывается, и каждый файл сверяется с оригиналом (SHA-256): результат публикуется, только если они идентичны.
  • Время NZip включает полную проверку архива, которую другие программы не выполняют.

Чтобы повторить замеры

  1. Установите NZip, 7-Zip 26.02 и, при желании, WinRAR 7.13 и zstd 1.5.7; также потребуется Python 3.
  2. Скачайте скрипты bench_data.py (вместе с bench_data.sha256.json) и bench.py.
  3. Выполните: python bench_data.py dati — скачивает и проверяет тестовые данные в папке «dati».
  4. Выполните: python bench.py risultati.json "Codice sorgente=dati\sorgenti" "Backup di sorgenti=dati\backup" Immagini=dati\immagini Documenti=dati\documenti
  5. Сравните файл risultati.json с опубликованными исходными данными.

Частые вопросы

NZip действительно бесплатен даже для компаний?

Да. Редакция NZip бесплатна для всех и для любых целей, включая коммерческие. Pro и Enterprise добавляют расширенные функции для специалистов и компаний.

Нужно ли получателю файла .nzip устанавливать NZip?

Чтобы открыть .nzip, нужен бесплатный NZip. Если получатель не может ничего устанавливать, с NZip Pro можно создать самораспаковывающийся архив (.exe), который открывается двойным щелчком.

Может ли NZip заменить WinRAR или 7-Zip?

Да: он открывает и распаковывает ZIP, RAR, 7z и другие распространённые форматы и может стать программой по умолчанию. При удалении прежние ассоциации файлов восстанавливаются.

Смогу ли я открыть свои архивы в будущем?

Да. Формат документирован, каждая версия NZip обязана бит в бит распаковывать архивы всех предыдущих версий, а распаковка всегда остаётся бесплатной.

Отправляет ли NZip данные в интернет?

NZip не отправляет ваши файлы и личные данные. Приложение раз в день проверяет на GitHub, есть ли новая версия (анонимный запрос, отключается в настройках); в Windows обновление устанавливается только после проверки цифровой подписи автора. Лицензии активируются подписанным файлом, без онлайн-проверок.
