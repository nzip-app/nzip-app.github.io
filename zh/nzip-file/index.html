.nzip

.nzip 文件扩展名

扩展名为 .nzip 的文件是一种压缩包：与 ZIP 文件一样，它包含一个或多个经过压缩的文件和文件夹，由 NZip 程序创建。

.nzip 文件是什么

.nzip 格式旨在生成更小、更安全的压缩包：以无损 JPEG XL 压缩 PNG 图像的像素，无损再压缩 JPEG 图像、ZIP 文件和 Office 文档，并为每个文件保存 BLAKE3 指纹，以验证解压内容与原始文件完全一致。

.nzip 压缩包可以设置密码保护（AES-256，同时加密文件名），可以包含恢复数据以便在损坏时修复，也可以进行数字签名或分割为多个分卷。

如何打开 .nzip 文件

  1. 下载 NZip，对所有人免费，支持 Windows、macOS 和 Linux。
  2. 双击 .nzip 文件：NZip 将打开并显示其内容。
  3. 选择“全部解压”，或在 Windows 上右键单击文件 → “解压到此处”。每个解压出的文件都会经过校验。

如果接收方无法安装程序，NZip Pro 可以创建双击即可打开的自解压压缩包（.exe）。

关于 .nzip 文件的常见问题

可以用 7-Zip 或 WinRAR 打开 .nzip 文件吗？

不可以：.nzip 文件需要用免费的 NZip 打开。而 NZip 还能打开 ZIP、RAR、7z 以及其他常见格式。

.nzip 文件安全吗？

压缩包只是一个容器：其安全性取决于其中包含的文件以及发送者是谁。NZip 会校验每个文件的完整性，但不能替代杀毒软件。

如何将 .nzip 文件转换为 ZIP？

用 NZip 解压内容，然后将文件夹重新压缩为 ZIP 格式。反过来，NZip 只需一次点击即可将 ZIP、RAR、7z 等格式转换为 .nzip。

压缩包已损坏：能恢复吗？

可以，前提是创建时包含了恢复数据：NZip 可通过“工具”菜单或 nzip r 命令进行修复。

NZip 提示该压缩包需要更新的版本，为什么？

该压缩包使用了较新版本 NZip 才有的功能，例如 PNG 图像的 JPEG XL 压缩（NZip 3.2）。请从官方网站免费更新 NZip：新版本始终能打开旧版本创建的压缩包。
