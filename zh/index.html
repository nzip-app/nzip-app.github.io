为什么选择 NZip

比 7-Zip 更小

PNG 图像像素以无损 JPEG XL 存储，对 JPEG、ZIP 和 Office 文档进行再压缩，并针对每种数据类型选用现代压缩算法。

逐一校验每个文件

在完成压缩包之前，NZip 会重新读取压缩包，并将每个文件与原始文件比对（BLAKE3）。解压时每个文件都会再次校验。

可修复

恢复记录可以修复因磁盘故障或下载出错而损坏的压缩包。

支持所有格式

打开并解压 ZIP、RAR、7z、TAR、GZ、BZ2、XZ、ZSTD、LZH、ARJ、CAB、ISO、WIM 等格式，一键转换为 .nzip。

安全可靠

AES-256 加密文件内容和文件名。使用 NZip Pro：数字签名和面向收件人的加密，无需交换密码。

深度集成系统

Windows 11 和 10 文件资源管理器右键菜单、“发送到”、预览和图标；macOS 上的 Finder；Linux 上的 Dolphin、Nautilus 和 Nemo。

永久可读

公开且有文档的格式、确定性压缩、每个版本都校验参考压缩包：今天的 .nzip，20 年后依然能打开。

7 种语言

Italiano、English、Español、Français、Deutsch、Русский、中文：程序、菜单和命令行。

与 ZIP、7-Zip、RAR 等对比

相同的文件夹、相同的电脑、可重复的测量。条越短，压缩包越小。每个程序生成的每个压缩包都经过解压，并与原始文件逐字节比对。

测试数据

  • 源代码 — CPython 3.13.7 官方源代码，文件 Python-3.13.7.tar.xz，来自 https://www.python.org/ftp/python/3.13.7/（PSF 许可证）。
  • 源代码备份 — 项目的备份文件夹，并排存放 CPython 的三个连续官方版本 3.13.5、3.13.6 和 3.13.7（文件 Python-3.13.x.tar.xz，来自 https://www.python.org/ftp/python/，PSF 许可证）：代表为每个版本保留一份副本的做法。
  • 图像 — Kodak Lossless True Color Image Suite 的 24 张 PNG 图像，来自 https://r0k.us/graphics/kodak/（由 Kodak 发布，可自由使用），以及来自 NASA Image and Video Library（https://images.nasa.gov）的 40 张 Apollo 11 任务原始 JPEG 照片（公有领域）。
  • 文档 — Govdocs1 语料库的第 000 块（从美国政府网站收集的文档，公有领域，为研究而创建），文件 000.zip，来自 https://digitalcorpora.org/corpora/file-corpora/files/

bench_data.py 脚本从上述来源下载所有文件并校验其 SHA-256 指纹，因此任何人都能获得完全相同的数据。

方法

  • 每个程序运行一次，全部在同一台电脑上进行，且文件夹已预先读取一次（所有程序条件相同）。
  • 每个程序均使用其开发商文档中注明的最高压缩设置；7-Zip 另外测试了标准设置。
  • 测量压缩包的字节大小，以及每条命令从开始到结束的用时。
  • 每个压缩包都会被解压，并将每个文件与原始文件进行比对（SHA-256）：只有完全一致的结果才会被公布。
  • NZip 的用时包含对压缩包的完整校验，其他程序不执行此步骤。

重复测量的步骤

  1. 安装 NZip、7-Zip 26.02，如有需要，还可安装 WinRAR 7.13 和 zstd 1.5.7；此外还需要 Python 3。
  2. 下载 bench_data.py 脚本（及 bench_data.sha256.json）和 bench.py。
  3. 运行：python bench_data.py dati — 在“dati”文件夹中下载并校验测试数据。
  4. 运行：python bench.py risultati.json "Codice sorgente=dati\sorgenti" "Backup di sorgenti=dati\backup" Immagini=dati\immagini Documenti=dati\documenti
  5. 将 risultati.json 文件与已公布的原始数据进行比较。

常见问题

NZip 对企业也真的免费吗？

是的。NZip 版本对任何人、任何用途免费，包括商业用途。Pro 和 Enterprise 为专业人士和企业提供高级功能。

收到 .nzip 文件的人需要安装 NZip 吗？

打开 .nzip 需要免费的 NZip。如果对方无法安装任何软件，您可以用 NZip Pro 创建自解压压缩包（.exe），双击即可打开。

NZip 能替代 WinRAR 或 7-Zip 吗？

可以：它能打开并解压 ZIP、RAR、7z 等常见格式，并可设为默认程序。卸载时会恢复之前的文件关联。

我的压缩包将来还能读取吗？

能。格式有公开文档，每个 NZip 版本都必须逐位解压所有旧版本创建的压缩包，而且解压功能永远免费。

NZip 会向互联网发送数据吗？

NZip 不会发送您的文件或个人数据。应用每天在 GitHub 上检查一次是否有新版本（匿名请求，可在设置中关闭）；在 Windows 上，只有在验证作者的数字签名后才会安装更新。许可通过签名文件激活，无需在线验证。
